# SignalForge MVP

Goal:
Build a demo-ready MVP that showcases AI-powered execution intelligence.

Primary User:
Engineering Manager

Primary Flow:

1. Upload or select engineer evidence.
2. Analyze engineering capability.
3. Display execution profile.
4. Display project fit score.
5. Recommend team composition.

Must Have:

- Dashboard
- Engineer Analysis
- Capability Scores
- Project Recommendations
- AI Explanation

Should Not Build:

- Authentication
- Complex database
- Kubernetes
- Microservices
- Real integrations

Success Metric:
Judges understand the problem, trust the analysis, and see a clear business use case.

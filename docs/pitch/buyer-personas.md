# Buyer and User Personas

SignalForge evaluates **delivery-system risk, capability coverage, dependencies
and evidence**. It is **not** intended to rank individual employees or automate
employment decisions.

## Primary economic buyer — CTO / VP Engineering

| Dimension | Detail |
|---|---|
| Business problem | High-stakes initiatives greenlit without evidence-backed readiness |
| Current workflow | Status meetings, PM tools, tribal knowledge |
| Pain | Late discovery of capability/dependency/key-person risk |
| SignalForge value | Portfolio-level readiness narrative with citations |
| Evidence needed | Sample briefs, security posture, POC success metrics |
| Objections | “Another dashboard”; model accuracy skepticism |
| Successful outcome | Uses briefs in exec reviews; sponsors POC go/no-go |
| Surfaces | `/briefing`, CoS briefs, scenarios, security questionnaire |

## Primary operational buyer — Engineering Operations / Program leadership

| Dimension | Detail |
|---|---|
| Business problem | Cross-team delivery risks hard to assemble before steering forums |
| Current workflow | Manual readiness docs, RAID logs, spreadsheet rollups |
| Pain | Stale ownership and dependency data; weak scenario planning |
| Value | Graph findings + scenario workshops + review workflow |
| Evidence needed | Finding precision/usefulness in pilot initiatives |
| Objections | Data onboarding cost; connector gaps |
| Outcome | Repeatable readiness ritual with owned follow-ups |
| Surfaces | Briefing, scenarios, assessments, data onboarding plan |

## Primary users

| Persona | Problem | Surfaces |
|---|---|---|
| Engineering directors | Portfolio heat without explainability | Briefing, briefs |
| Engineering managers | Team-initiative fit and gaps | Readiness UI, findings |
| Platform leaders | Shared-platform bottlenecks | Graph findings, scenarios |
| Program managers | Initiative dependency risk | Scenarios, briefs |
| Architecture leaders | Structural delivery constraints | Graph, capability gaps |

## Reviewers

| Persona | Focus | Artifacts |
|---|---|---|
| Security | Authn/z, tenancy, audit, secrets | Security questionnaire |
| Data governance | Retention, deletion, identity mapping | Data onboarding plan |
| Enterprise architecture | Hosting, identity, integration map | Microsoft POC blueprint |
| Procurement | Commercial/risk packaging | One-pager + evidence index (no fabricated traction) |

## Positioning guardrail

Reject any framing that treats SignalForge as developer surveillance, stack
ranking, or HR automation. PR counts are not productivity.
